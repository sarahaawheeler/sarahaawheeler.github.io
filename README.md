# Sarah's personal website starter

A simple, responsive static website designed for GitHub Pages. No framework, build steps, tracking scripts, or dependencies.

## Preview locally

Open `index.html` in any modern browser. The layout works without a server.

## Personalize before publishing

1. Update the introduction and biography in `index.html`.
2. Replace all three sample work entries with accurate titles, descriptions, and project links. Remove the editorial note after doing so.
3. Replace `YOUR_EMAIL@example.com` in **both places**, and update the generic GitHub and LinkedIn links.
4. Add a `cv.pdf` file in the repository root and uncomment the CV link if desired.
5. Adjust the colors in the `:root` section of `styles.css` if desired.
6. Remove unfinished sections rather than presenting placeholders as completed work.

## Publish to GitHub Pages (no command line needed)

1. Create a public GitHub repository called `YOURUSERNAME.github.io` (replace `YOURUSERNAME` with your exact GitHub username).
2. Upload `index.html`, `styles.css`, and `.nojekyll` to the *root* of the repository via **Add file → Upload files**. `README.md` can also be uploaded.
3. Commit the files to the default `main` branch.
4. Open **Settings → Pages → Build and deployment**. Select **Deploy from a branch**, then **main**, then **/(root)**, and save.
5. Visit `https://YOURUSERNAME.github.io/` once publishing completes.

For later edits, edit the files directly on GitHub or use VS Code / GitHub Desktop and push changes to `main`.

GitHub documentation: https://docs.github.com/en/pages/quickstart
